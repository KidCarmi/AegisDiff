Zero code egress

AegisDiff runs entirely inside your GitHub Actions runner. Your source code never leaves GitHub's infrastructure. We never see it, store it, or transmit it. Only the verdict (metadata) is sent to the dashboard.

  • ✓ Engine runs in your GitHub Actions environment
  • ✓ LLM API calls are made from your runner, using your own keys
  • ✓ Only verdict metadata stored in our database (no code quotes)
  • ✓ Evidence shown only in the GitHub PR comment — on GitHub's servers
